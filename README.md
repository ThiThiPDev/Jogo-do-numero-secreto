# 🎲 Jogo do Número Secreto <br>

<p align='justify'>
Este jogo contém um número secreto, sorteado aleatoriamente entre 1 e 10. O objetivo é descobrir qual é esse número utilizando o menor número de tentativas possível. A cada erro, o jogo fornece dicas indicando se o número secreto é maior ou menor que o valor informado, ajudando o jogador a chegar à resposta correta.

### ✔️ Funcionalidades 

- **Sistema de dicas**: Sempre que um palpite estiver incorreto, uma dica será exibida indicando se o número secreto é maior ou menor do que o valor informado.
- **Registro de tentativas**: Ao acertar o número secreto, o jogo informa a quantidade total de palpites realizados até a vitória.
- **Design responsivo**: Interface adaptada para smartphones, tablets e computadores, garantindo uma boa experiência em qualquer tamanho de tela.
- **Responsive Voice**: O projeto utiliza a biblioteca Responsive Voice, responsável por realizar a leitura em voz alta dos textos exibidos na página. Esse recurso proporciona uma experiência mais imersiva, alinhada ao estilo cyberpunk do jogo, além de aumentar a acessibilidade para pessoas com deficiência visual. Para ativar a narração, basta clicar em "Allow" quando a página for carregada.
